Features of this webpage.

Web programming starts with HTML. Every page is a set of nested elements that describe what the content is, not how it looks.

CSS handles how it looks. A stylesheet matches elements by tag, class, or id, then sets things like font, color, spacing, and layout.

The browser puts the two together. It reads the HTML from top to bottom, builds the structure, then applies the matching style rules to each element.
